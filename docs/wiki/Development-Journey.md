# 예보에서 발전량, 정산 점수까지

## 기상 특징과 target

LDAPS/GFS 예보와 그룹 설비 정보에서 시작했습니다. 풍속·시간·공간 요약과 결측 정보를 구성하고, 미래 관측을 과거에 사용하지 않도록 예보 시점과 target 시간을 맞춥니다.

여러 그룹을 같이 학습하는 shared 모델은 용량 차이를 제거한 capacity factor를 사용합니다. 그룹별 발전량은 예측 후 용량을 곱해 복원합니다.

## L1과 quantile 후보

절대 오차를 줄이는 기본 후보에 quantile 후보를 추가했습니다. 평가는 NMAE뿐 아니라 오차 6%·8% 경계를 가진 발전량 가중 정산금 비율을 사용하기 때문입니다. 후보를 따로 학습하고 정해진 recipe로 조합하며, 단일 손실의 개선을 전체 점수 개선과 동일시하지 않습니다.

개발 선택은 2022 학습→2023 검증의 그룹 1·2에서 이뤄졌습니다. 2024의 그룹 1·2·3 검증은 역할과 범위가 다릅니다.

## Shared 모델 단위 오류

후속 final trainer가 개발 recipe와 달리 shared target을 kWh로 학습한 불일치가 있었습니다. Shared L1·quantile target을 capacity factor로 맞추고 그룹 용량으로 복원했습니다. 당시 수정은 가중치·특징·hyperparameter를 다시 찾는 실험과 구분했습니다.

이미 2024 정답을 본 뒤였으므로 수정 결과는 독립 검증이 아닙니다. 최초 기록과 수정 기록을 둘 다 남기는 것이 중요합니다.

## SCADA와 추가 모델의 선택

풍속 auxiliary가 도움이 될 수 있다는 가설로 SCADA 경로를 비교했지만, 당시 동일 2022→2023 검증에서 기준보다 약 0.000981 낮았습니다. 결과가 나빠진 보조 경로는 recipe에서 제외했습니다.

이 결정은 모든 외부 데이터가 쓸모없다는 뜻이 아닙니다. 입력이 실제로 사용 가능한 시점과 같은 평가조건의 이득을 따로 확인해야 한다는 의미입니다.

## Public scale과 과적합 경계

2025 공개 평가에서는 global scale을 살폈습니다. 당시 기록의 0.92·0.95·0.97 scale 중 0.97이 더 높았지만, 이 선택은 공개 피드백을 사용한 후처리입니다. 새로운 독립 데이터의 성능으로 볼 수 없습니다.

그룹·기간을 잘게 나눠 숨은 평가구간의 기여를 역산하는 탐색은 사용하지 않는 방향으로 정리했습니다. 공개 점수를 계속 좇는 대신 평가정보 사용 이력을 구분했습니다.

## 외부 예보 복구의 한계

NOAA GEFS 예보 자료도 별도로 검토했지만, 보존된 기록에서는 추출 단계 호환 오류로 해당 경로가 종료됐습니다. 입력 확보와 모델 성능은 다른 단계이므로 새 예보를 확보했다는 사실을 성능 향상으로 쓰지 않습니다.
