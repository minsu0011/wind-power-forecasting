# 개발·검증·공개 평가의 구분

2022→2023 그룹 1·2의 개발 실험에서 recipe를 정했습니다. 2024 그룹 1·2·3 평가 뒤 shared target이 kWh로 학습된 불일치를 발견해 capacity factor와 용량 복원을 맞췄습니다. 수정 결과도 이미 사용한 검증의 재계산입니다.

SCADA 보조 경로는 동일 개발 비교에서 점수가 낮아 제외했습니다. 2025의 global scale 선택은 공개 피드백을 사용한 후처리이므로 독립 검증이 아닙니다.

기간·그룹이 다른 결과를 하나의 향상률로 묶지 않습니다. [실험 흐름](wiki/Development-Journey.md) · [당시 수치](wiki/Validation-and-Results.md)
